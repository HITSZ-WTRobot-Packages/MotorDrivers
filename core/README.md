# MotorDrivers::Core

本目录是 `MotorDrivers::Core` 包，边界由 [cpkg.toml](cpkg.toml) 定义，依赖 `Core::IController`（传递依赖 `libs::Concurrency`）。它提供统一电机接口、控制模式和控制器基类，不提供独立固件或硬件初始化。全仓集成顺序见 [根 README](../README.md#can-接入方式)。

## 抽象与分工

电机驱动负责反馈解析、状态和协议命令，控制器负责选择控制路径与闭环计算。上层通过反馈、输入能力、控制权三个维度使用电机，而不是按型号判断。

输入能力分为低层电流 / 力矩、内部速度、内部位置、MIT 五元组。内部速度和位置能力还区分“仅参考值”和“参考值加限制”：不支持最大电流或最大速度的协议可能忽略相应参数，不能把同一个函数签名当成相同的设备能力。

## 单位与能力边界

- 角度通常是输出轴 `deg`，普通速度是输出轴 `rpm`，力矩是 `Nm`；明确带 `_rad` 等后缀的量以其标注为准。
- `resetAngle()` 是软件重定义当前输出角度零点，不等同于写入电机机械零位。
- `setCurrent()` 表示最低层输出，物理量由驱动决定：DJI 使用协议电流指令，VESC 使用电流，DM / MI 的 MIT 退化输入使用力矩。PID 输出限幅必须采用所选驱动的量纲。
- MIT 的速度项与位置参考配套，不自动沿用普通速度的 `rpm`；DM / MI 的位置参考均为输出轴 `deg`（与 `getAngle()` 使用相同的软件零点和展开坐标），配套速度为输出轴 `deg/s`。驱动恢复方向、减速比、软件零点及当前圈数后，再按协议范围限幅与编码。范围与型号换算约束见各电机包。
- `kNoLimit` 是不施加额外限制的哨兵，不代替驱动器物理量程、配置限幅或宿主安全保护。
- 不支持的 `apply*` 扩展点默认忽略输入，不能以“调用后没报错”判断功能可用；应先查询能力。公开 `set*` 包装还会拒绝 `Disabled/Protected` 状态的目标。

## 控制模式

| 模式 | 意义 |
| --- | --- |
| `Default` | 使用电机驱动返回的默认模式 |
| `ExternalPID` | MCU 计算输出，通过低层电流 / 力矩接口下发 |
| `InternalVel` | 使用驱动器内部速度输入 |
| `InternalPos` | 使用仅位置输入的设备 |
| `InternalVelPos` | 设备同时具备内部速度与位置输入 |
| `InternalMIT` | 驱动可接收 MIT 五元组 |

模式描述能力的用法，不等于所有控制器都实现该模式的全部语义。尤其两个 [通用控制器](../controllers/README.md) 对 `InternalMIT` 实际走外部 PID，不直接发送 MIT 五元组；速度控制器也不支持 `InternalPos`。

显式模式的能力检查使用 `assert`，关闭断言时不能指望其拒绝错误配置。`Default` 直接取驱动默认模式，也不能代替宿主核对硬件与控制路径。

## 控制权与寿命

`IMotor` 继承 `core::control::IController<0>`；电机专用的 `controllers::IController` 继承 `IController<1>`，以非空 `IMotor*` 作为唯一候选子节点。固定候选引用不拥有对象，构造不取得控制权，也不进行硬件初始化。电机和控制器都不可复制、移动。

根节点成功 `enable()` 后为 `Protected`，被父节点取得的子节点为 `Controlled`。独立使用时先成功 `enable()`，再成功 `standalone()`，然后设置参考并周期更新。所有生命周期返回值都需要处理；使能失败由 Core 回滚本轮关系和新使能的节点。`Standalone` 电机不能被控制器隐式接管，须先返回保护态或失能。

电机公开 `setCurrent/setInternalVelocity/setInternalPosition/setInternalMIT` 仍在 `Standalone/Controlled` 调用驱动 `apply*`，不增加来源鉴别。两个通用控制器的直接入口 `setRef()` 仅在 `Standalone` 接受；父节点入口 `setRefFrom(source, ...)` 仅在 `Controlled` 且 `currentController() == &source` 接受。`Disabled/Protected` 拒绝两个入口，`Controlled` 拒绝直接入口，`Standalone` 拒绝父节点入口。拒绝返回 `false`，不修改参考、限幅、前馈、分频或输出；接受返回 `true`，只表示更新参考，不表示底层发送或硬件执行成功。

来源比较针对控制器自身的当前父节点，不重复检查电机持有关系，也不检查来源节点的状态；父节点保护钩子执行时自身状态可能尚未提交，但它已取得的子节点仍可接受其来源。两个入口通过检查后复用同一参考更新实现。`Protected` 不接受新参考，但已使能控制器的 `update()` 继续执行安全参考；保护会清 PID 与分频，速度归零，位置保持保护瞬间反馈。位置保持需要宿主保证有效反馈。

显式来源是调用者声明，公开父节点指针仍可被用来冒充，不属于不可伪造凭证。`getMotor()` 及原始电机 setter 的旁路语义不变；本包不提供全设备写权限隔离。状态和来源检查仍依赖宿主将业务与生命周期串行化，不构成原子授权事务。

`disable(false)` 失能本节点及活动上级，释放的直接子节点保持 `Protected` 且保留自身下级。无控制者的根节点可用 `disableTree()`（等同 `disable(true)`）关闭活动子树；受控节点不能执行逆向整树失能。这些是逻辑关系，不等于物理断电或电机已执行停机。

电机 `selfProtect/selfDisable` 必须使用内部 `apply*` 或协议 helper，不能通过公开状态门控跳过必要输出，因为钩子执行时状态可能尚未提交。控制器保护钩子可以向已经归自己控制的电机发送安全目标；钩子不手动释放控制关系、不调用其他节点生命周期。各驱动的具体保护、发送错误和协议边界见其包说明。

控制器借用电机，电机必须覆盖控制器寿命；所有节点必须成功失能后再析构，控制器先于电机销毁。析构只检查 Core 的失能前提，不自动停机或释放控制权。候选树必须无环且不能沿多条路径重复触达同一个电机；固定候选拓扑不是支持共享叶的资源 DAG。

Core 的非阻塞生命周期锁不保护参考、PID、反馈或 CAN 发送，宿主必须串行化这些操作与任务/ISR 调用；状态/父指针快照不是完整一致快照或硬件安全联锁。旧 `controller_` 仲裁和 `enabled()` 已删除，外部调用方迁移边界见 [根 README](../README.md#生命周期迁移)。

具体符号、参数与默认实现以 [motor_if.hpp 中的 Doxygen](motor_if.hpp) 为准；CAN 回调借用及更长的电机寿命要求见 [全仓接入契约](../README.md#初始化与寿命)。
